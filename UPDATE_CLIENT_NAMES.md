# Обновление имен клиентов в базе данных

Этот скрипт обновляет все имена клиентов в базе данных, приводя их к нижнему регистру для обеспечения консистентного поиска по кириллице.

## Запуск скрипта

### На продакшене:

```bash
# 1. Перейти в папку бэкенда
cd /path/to/AccountingForRepairsBackend

# 2. Создать резервную копию базы данных
npm run backup-db

# 3. Запустить скрипт обновления
npm run update-client-names-to-lowercase
```

### Локально (для тестирования):

```bash
# Перейти в папку бэкенда
cd AccountingForRepairsBackend

# Запустить скрипт обновления
npm run update-client-names
```

## Что делает скрипт

1. **Показывает статистику до обновления:**
   - Примеры имен клиентов
   - Общее количество уникальных имен

2. **Обновляет имена клиентов:**
   - Приводит все имена к нижнему регистру
   - Показывает прогресс обновления
   - Считает количество обновленных записей

3. **Показывает статистику после обновления:**
   - Примеры обновленных имен
   - Общее количество уникальных имен

## Безопасность

- **ВАЖНО:** Создайте резервную копию базы данных перед запуском скрипта
- Обновляет только имена клиентов, не затрагивая другие поля
- Показывает детальную статистику изменений
- Безопасно запускать несколько раз (не обновляет уже обновленные записи)

## Скрипт бэкапа

Для создания резервной копии базы данных используйте:

```bash
npm run backup-db
```

Этот скрипт:
- Создает папку `backups` в текущей директории если её нет
- Копирует `db.sqlite` в `backups/db_backup_YYYYMMDD_HHMMSS.sqlite`
- Показывает сообщение об успешном создании бэкапа

## После обновления

После успешного обновления:
- Поиск по именам клиентов будет работать независимо от регистра
- Имена будут отображаться с заглавными буквами для красоты
- Новые записи будут автоматически сохраняться в нижнем регистре
